💻 Development

Clone the repository:

git clone https://github.com/Saugata15/Ease-Ui.git

Navigate into the project:

cd Ease-Ui

Install dependencies:

npm install

Start the development server:

npm run dev

🏗️ Build

Build the EaseUI package:

npm run build

Preview the production build:

npm run preview
